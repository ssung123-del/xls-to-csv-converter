# 📊 XLS to CSV 변환기

가벼우면서도 강력한 **웹 기반 엑셀(XLS/XLSX) to CSV 변환 및 병합 도구**입니다. 별도의 서버 설치나 복잡한 의존성 없이 로컬 브라우저 환경에서 단일 HTML 파일(`index.html`)만으로 즉시 구동됩니다.

## ✨ 주요 기능

- **다중 파일 병합 (Union Headers)**
  - 여러 개의 엑셀 파일을 하나로 합칠 때, 각 파일의 헤더(열) 구성이 달라도 **모든 헤더를 통합(Union)** 하여 데이터의 유실 없이 안전하게 병합합니다.
  - 존재하지 않는 컬럼의 데이터는 자동으로 빈칸 처리됩니다.
- **성능 최적화 (프리징 방지)**
  - 대용량 파일 변환 시 브라우저 UI가 멈추지(Freezing) 않도록, 주요 연산 사이에 메인 스레드를 양보(`yieldToMain`)하는 비동기 최적화가 적용되어 있습니다.
  - 진행률(Progress Bar)이 실시간으로 부드럽게 렌더링 됩니다.
- **직관적인 UI / UX**
  - 드래그 앤 드롭(Drag & Drop)으로 편리하게 파일을 업로드할 수 있습니다.
  - 업로드된 파일들의 순서를 드래그하여 자유롭게 변경할 수 있습니다.
- **다크/라이트 모드 지원**
  - 시스템 및 사용자 설정에 맞는 세련된 테마 전환 기능을 제공하며, 프리미엄 글래스모피즘(Glassmorphism) 스타일이 적용되어 있습니다.
- **데이터 미리보기 및 정렬**
  - 변환 전 각 파일의 데이터(최대 10행)와 통계(행/열 수)를 미리 볼 수 있습니다.
  - 날짜, 숫자, 문자형을 자동 감지하여 특정 컬럼을 기준으로 데이터를 정렬할 수 있습니다.

## 🚀 사용 방법

1. 프로젝트 폴더 내의 `index.html` 파일을 더블 클릭하거나, 최신 웹 브라우저(Chrome, Safari, Edge 등) 화면 위로 드래그하여 실행합니다.
2. 변환할 `.xls` 또는 `.xlsx` 파일들을 점선으로 된 업로드 영역에 드래그 앤 드롭합니다.
3. (선택) 업로드된 파일의 순서를 마우스 드래그로 조정합니다.
4. 하단의 **'변환 옵션'**에서 모드(병합 또는 개별 변환), 정렬 기준, 헤더 포함 여부를 선택합니다.
5. **'변환 및 다운로드'** 버튼을 클릭하면 `.csv` 파일이 로컬로 안전하고 빠르게 다운로드됩니다.

## 🛠 기술 스택

- **Frontend:** 순수 HTML, CSS (CSS Variables), JavaScript (Vanilla)
- **Library:** [SheetJS (xlsx)](https://sheetjs.com/) - 엑셀 파일 파싱 및 조작
- **Architecture:** 단일 파일 렌더링 (Single File Tool) - 모든 CSS와 JS 로직이 하나의 `index.html`에 포함되어 있어 배포 및 공유가 매우 간편합니다.

## 📝 최근 업데이트 변경사항

- **UI/UX 개선:** Webkit 기반 브라우저(Chrome/Safari)용 커스텀 스크롤바 디자인 적용 및 포커스 접근성 강화.
- **안정성 개선:** 멀티 파일 병합 시 첫 번째 파일의 헤더만 참조하여 다른 파일의 고유 데이터가 소실되던 치명적 결함을 **통합 헤더(Union Headers)** 방식으로 해결.
- **성능 개선:** 대용량 파일 변환 시 브라우저 프리징을 막기 위해 UI 렌더링을 양보하는 대기열(`yieldToMain`) 시스템 도입.
